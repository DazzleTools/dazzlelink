### Behavioral observations (not regressions)

1. **Two result lines from `dazzlelink rebase`**: the command prints one `Results:` line from
   `rebase_links` (live-symlink rebase, old format: no `skipped` column) and one from
   `rebase_dazzlelinks` (record-file rebase, new format: includes `skipped`). This is pre-existing
   0.8.0 behavior. Not new in 0.9.0; not a regression. A future UX pass could unify the output.

2. **`dazzlelink recreate` is not a top-level command**: the checklist says "recreate/import
   command of your choice." The tool exposes recreate via `import` (batch) and `import <file>`
   (single). There is no `dazzlelink recreate` subcommand. This matches 0.8.0 behavior.
