## Notable Observations

**BOM issue in hand-editing:** PowerShell `Set-Content -Encoding UTF8` writes a UTF-8 BOM. `rebase_dazzlelinks` opens files with `encoding='utf-8'` (BOM-intolerant). If users hand-edit `.dazzlelink` files with a tool that writes BOM, rebase will fail with "Unexpected UTF-8 BOM (decode using utf-8-sig)". Workaround: use `encoding='utf-8-sig'` in the open call, or document that files must be BOM-free. This is a pre-existing constraint not introduced by the new code -- the existing `json.load` in batch.py line 1022 is the site. Not a blocker for SHIP; filed as observation.

**Monolith parity (execute --mode info):** The modular package shows an additional `Original Path:` line that the monolith omits. All GT-8 fields (Relative Path, Exists, Size, Type) match exactly. The extra field is additive and not a regression.

**Symlink privilege (Section 2.1):** Windows required admin elevation for `New-Item -ItemType SymbolicLink`. SKIP(privilege) applied per checklist instructions. Dazzlelink pass confirmed running via printed output. CLI wiring confirmed in source.
